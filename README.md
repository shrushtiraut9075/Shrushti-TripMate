# Shrushti TripMate

A web-based travel planning application for organizing trips, itineraries, locations, checklists, notes, and travel expenses.

**Repository:**
https://github.com/shrushtiraut9075/Shrushti-TripMate

---

## Overview

Shrushti TripMate is designed to provide a centralized workspace for planning and managing travel activities.

The application focuses on organizing trip information into separate modules such as itinerary planning, map-based location viewing, travel checklists, notes, and budget management.

---

## Features

### Trip Management

* Create and manage trips
* Add destination and travel dates
* View trip details
* Track trip planning progress

### Itinerary

* Create day-wise schedules
* Add activities with date and time
* Add activity locations and categories
* Update and remove itinerary items

### Map View

* Display trip destinations
* View important travel locations
* Associate locations with itinerary activities

### Checklist

* Create travel preparation tasks
* Organize tasks by category
* Mark tasks as completed
* Track checklist progress

### Notes

* Create trip-specific notes
* Edit and delete notes
* Store important travel information

### Budget

* Set a trip budget
* Record expenses
* Categorize expenses
* Track spending and remaining budget

## Getting Started

### Prerequisites

Install:

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/shrushtiraut9075/Shrushti-TripMate.git
```

### Navigate to the Project

```bash
cd Shrushti-TripMate
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

Open the local development URL displayed in the terminal.

## Environment Configuration

If the application requires API keys, create a `.env` file based on:
